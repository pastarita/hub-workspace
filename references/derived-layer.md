# hub-workspace · the derived-data layer

The Model splits in two as soon as any figure has an upstream source outside the workspace.

- **`<ns>-data.js` — AUTHORED.** Judgements: records, scores, decisions, tokens. A human wrote
  every value. The generator never touches it.
- **`<ns>-derived.js` — GENERATED.** Line one is
  `// GENERATED by <script> — do not hand-edit.` Payload is one global:
  `window.NS_DERIVED = {...}`. Every `DERIVED` badge in the workspace resolves from here.

Keep the split. The reason is a one-liner worth quoting in your `AGENTS.md`:

> **A diff should say plainly whether someone changed a judgement or a script recomputed a fact.**

Shape: `site/<ns>-data.js` (authored) + `site/<ns>-derived.js` (generated) +
`build_hub_data.py` (generator) + `check.py` (verifier).

---

## 1 · The generator

Reads the real sources — which normally live **outside** the deploy tree — computes every badged
figure, and **stages readable copies of its sources into the deploy**. The Viewer can only reach
paths inside the deploy artifact, so an unstaged source is a dead link.

Support `--check` (report, write nothing) so CI and humans can run it non-destructively.

```python
derived = {
  "ref": "NS-HUB-YYMM", "source_ref": inv.get("ref"), "cut": inv.get("cut"),
  "counts": { ... },        # every scalar any leaf renders
  "<records>": [...],       # per-entity rows, with computed predicates baked in
  "documents": [ {"file":"docs/x.md","title":…,"source":…,"kind":"md","bytes":…} ],
}
```

**Compute predicates in the generator, not per-leaf**, and store the boolean on the record:

```python
rec["gate"] = bool(rec["status"] == "catalog"
                   and rec["grade"] in ("L2", "L3")
                   and rec["publish"] == "clear")
```

One definition, one place — and the checker then has something to independently re-derive.

Record the upstream chain in `AGENTS.md`: *re-run after any edit to X, Y, Z.*

---

## 2 · The verifier — `check.py` / `check.mjs`

A **second, independent implementation**. Re-reading the generator's output proves nothing. Four
jobs:

**1. Lint the Shell contract.** Every registered slug has a file, a glyph, an ordinal and a hub
card; every leaf links the tokens file and the Shell; no leaf reaches an external host; every
`<table>` sits in a `.tscroll`; the Viewer has a glyph but no card.

**2. Recompute every derived count from the real sources** and assert equality:

```python
bad(f"DERIVED MISMATCH {k}: derived says {got[k]}, sources say {v}")
```

**3. Assert structural invariants, not just values.** A funnel of successive predicates must be
**monotonically non-increasing** — if it is not, the story it tells reads wrong, and no badge
catches that.

**4. Re-derive the falsifiable prose claims.** This is the one most workspaces skip.

When a leaf asserts something in *sentences* — "X holds first place under every preset", "Y never
reaches 2nd" — parse the authored model and check it. **Prose drifts silently the moment anyone
edits a score, and a stale claim in body text is not badge-protected.**

```python
orders = {n: order(dict(zip(FK, v))) for n, v in PRESETS.items()}
if not all(o[0] == "bls" for o in orders.values()):
    bad("ranking.html claims BLS is first under every preset — it is not: " + ...)
```

Also warn when a leaf appears to **hardcode** a number that lives in `counts` — the
"interpolate, never transcribe" rule, mechanized.

A clean run should say what it actually verified, not just "ok":

```
registered slugs : 8
recomputed       : 12 counts, independently from families.json + CSV
staged documents : 14 present
ranking claims   : 3 re-derived from the authored scores

✓ all checks pass (0 warning(s))
```

---

## 3 · Interpolate prose, not just figures

A derived *sentence* beats a correct-today sentence. Build the whole clause from the model and
badge it `derived`:

> **Logistics** is **7-of-7** unpriced and **opsoftware** is **5-of-6** …

built from `D.families` in the leaf that renders it.

---

## 4 · Anti-patterns

- A generated file with no `GENERATED by` header.
- A verifier that re-reads the generator's output instead of recomputing from source.
- A predicate re-expressed per leaf instead of stored once on the record.
- A prose claim about the model that no script re-derives.
- Sources referenced but not staged into the deploy artifact — dead links in the Viewer.
- Hand-editing the derived file "just this once" to fix a number.
